The repository keeps its history in documents. This index lists them all and links each to GitHub. Pages that are *living references* are also mirrored on this site (see the sidebar); everything else stays as the original file so it remains an accurate record of when it was written.

How to read the sections:

- **Living references** are updated as things change.
- **Reports, plans, sheets and audits** are accurate to the date they were written. They are never edited afterwards; a newer document supersedes them.
- **The archive** holds early specifications and reviews, frozen.

The 36-section task register and the tool reference are generated from the code; see [How this site is built](@development/site).
