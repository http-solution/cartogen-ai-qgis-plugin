# without it, the plugin has no working provider connectivity at all. Not listed here until the
# 2026-09-14 Community-lineage classification pass flagged the gap: it had always been present in

# unstated assumption about the host environment, not a declared dependency of this package.

# Pinned to a floor, unlike everything else in this file (QUAL-004, 2026-09-13 audit):
# duckduckgo-search has no official API -- it scrapes DuckDuckGo's own response format,
# has a documented history of breaking on upstream changes, and the PyPI package itself
# has since been renamed (duckduckgo-search -> ddgs, old name now a thin compat shim).
# >=8.1.1 is the version search_web (system_tools.py) is actually tested against; <9

duckduckgo-search>=8.1.1,<9
