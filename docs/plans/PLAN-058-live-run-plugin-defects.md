- 2026-11-04: DEF-24 (V4, issue 362) built. What the evidence showed: in both agent runs (2026-11-03, 2026-11-04) the layer was made temporal (step 1 passed) and the second request ("animate the layer over time") ended in a how-to; the model ran find_tools three times, tried a virtual layer (it failed) and gave manual Temporal Controller steps. The router offers `export_temporal_animation_frames` for that sentence and find_tools returns it for 9 of 11 phrasings tried, so why the model did not call it is **unconfirmed**; the project was unsaved, so there is no steps.jsonl for that turn. Two real mismatches in the tool itself were fixed: `start_field` was required even though `set_layer_temporal` had recorded it (now optional, read from the layer's temporal settings; with none, the error names the layer's date fields), and the description promised only start/end period layers (now says an events layer with a single date field fits). Offline tests fail on the old code and pass; a live test checks the real `temporalProperties()` calls (CI only). Whether the model now calls the tool is not known: row V4 must be rerun.
- 2026-11-04: DEF-25 (A1) built, cause inferred not reproduced. Evidence: the agent's pages (read from its returned PDFs) show a Legend with only its heading, a blank map frame and the footer "CRS unknown | Scale 1:232,624,042,192", while the same run's table said 7 layers were listed. The script ran after `QgsProject.clear()`, which leaves the project with no CRS, and never framed the canvas on its layers. In code, `_style_legend` always switched on QGIS's filter-by-map-content, which cannot keep layers it cannot place in an unknown CRS, and which the plugin already avoids for access maps because it "can silently drop a visible reach polygon" (rc11 S8). Fixed in the plugin: the legend filter is off when the map has no CRS or when no layer lies on the map (the legend then lists every layer), and the reply says why in plain words; it stays on when the map shows the data. Fixed in the script (a script fault, kind ROW): it sets the project CRS, frames the canvas on its layers and measures that the exported map intersects them. Offline tests fail on the old code and pass; a live test with a real canvas checks the three situations (CI only, first execution). Whether the legend was empty because of this exact path is not proven; the change only makes the legend list more, never less. Row A1 must be rerun and a person must look at the pages.
