# Persona catalogue

Generated by `python docs/generate_persona_catalogue.py` from `src/cartogen_ai/core/personas/*.json` and the task register. Do not edit by hand: `tests/test_persona_catalogue.py` fails when this file is out of date.

A persona is a lens, not a gate: it changes which tools are suggested first and how the assistant words its guidance. It never hides or blocks a tool, and it carries no licensing or tier logic. **Built** means a live run saw the capability working (`docs/LIVE_RESULTS.json`); **Available** means the tool exists and an automatic test covers it, which is weaker; **Not built** names the release of `docs/plans/PLAN-023-programme-1-18-2-to-1-30.md` that will deliver it.

## 1. GIS Generalist

`general` (also called: gis, generalist, analyst)

General GIS work: loading, converting, cleaning and checking spatial data, and producing maps and exports.

**Tools suggested first:** `add_layer_from_path`, `export_layer`, `reproject_layer`, `merge_layers`, `join_by_attribute`, `fix_geometries`, `diagnose_topology`, `validate_schema`, `write_provenance_sidecar`, `load_workflow_preset`, `run_processing_model`, `execute_pyqgis_script`

**Workflows:**

- Load, repair and check a dataset: `add_layer_from_path` -> `fix_geometries` -> `diagnose_topology` -> `validate_schema` -> `write_provenance_sidecar`
- Convert and reproject: `reproject_layer` -> `merge_layers` -> `join_by_attribute` -> `export_layer`

**Available (checked by automatic tests):**

- format conversion, reprojection, merge and join [export_layer]
- geometry repair and topology checks for validity, slivers and overlaps [diagnose_topology]
- schema contracts and P-code checks [validate_schema]
- provenance record beside every product [write_provenance_sidecar]
- reusable workflows: presets and saved models [run_processing_model]

**Not built yet:**

- topology rules beyond overlaps (gaps, must be covered by) - due in R8 (1.26.0)
- ISO 19115 metadata record - due in R8 (1.26.0)
- generic open-data portals (CKAN, ArcGIS Hub, Socrata) - due in R7 (1.25.0)

**Data sources:** Humanitarian Data Exchange (HDX) (open), Geocoding (OpenStreetMap Nominatim) (open)

**Style profile:** `general`

**Layout templates:** `standard`

**The assistant will:**

- Say which coordinate system a result is in and what was assumed when the request left it open.
- Never report a repair as complete without reading the topology check back.
