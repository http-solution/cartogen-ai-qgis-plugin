# Deep code audit, 2026-10-28

Dated snapshot (do not edit later; supersede with a new doc). Measured on `main` at `75e719c`, before PLAN-040 stage 0/3/4 merged
(#485 `c34ba21`, #486 `aaf6941`). Structure detail and stage list: `docs/plans/PLAN-040-codebase-structure-audit.md`.
Everything below is measured offline in a cloud sandbox. Nothing here was run in a real QGIS session.

## Verdict
The code is not "rubbish": no import-time cycles, security scan clean, QGIS 4.2 rules mostly followed, a large test suite. The real
costs are (1) a few very complex functions, (2) a flat 108-file tools package that is expensive to move, (3) ~15k fixed tokens sent per
request, (4) low offline coverage of the orchestration layer, (5) documentation sprawl. Each has a solution below; what is done is marked.
