01 — Brand Idea

Layers converge on a point.

Cartogen exists at the intersection of cartography and generation — a spatial agent that reads many layers of geographic data and resolves them into one precise, actionable answer. The identity is built on that single idea: contour rings, the universal language of terrain data, converging toward a single located point. Technical, not decorative. Field-instrument, not startup-generic.

02 — Logo

The mark

Three contour rings — navy, teal, and signal teal — open toward a single amber node: the point of insight the agent resolves from layered spatial data. Use the full lockup whenever space allows; the mark alone is reserved for icons, favicons, and constrained spaces.

PRIMARY LOCKUP — LIGHT
PRIMARY LOCKUP — DARK
MARK ONLY — FOR ICONS & FAVICONS
MONOCHROME — STAMPS, ENGRAVING, 1-COLOR PRINT

Clear space

Maintain clear space equal to the height of the node circle on all sides of the mark. Never let text, edges, or other marks intrude on this zone.

Minimum size

Mark alone: 24px minimum (digital), 8mm (print). Full lockup: 120px minimum width. Below this, use the mark-only version.

Never

Don't recolor the rings outside the approved palette, close the gap into a full ring, remove the node, or stretch the mark off-ratio.

05 — Voice

Sounds like a field instrument, not a hype machine.

Precise, not promotional

State what the agent did and why. No "revolutionary," no "game-changing." Let the tool call and the result speak.

"Buffered 500m around 14 facilities. 3 overlap the flood extent."

Show the work

Every claim is traceable to a tool, a parameter, a source. Voice never asserts what it can't cite from an actual step.

"CRS mismatch detected — layer A is EPSG:4326, layer B is EPSG:32636."

Field-tested, not theoretical

Grounded in real humanitarian and technical workflows — HDX, OSM, PostGIS — not generic AI-assistant language.

"Fetched admin4 boundaries for Syria from HDX. 3 features had topology errors."

Calm under load

Security, failure, and edge cases are described plainly and specifically, never buried in reassurance.

"Read-only enforcement could not be confirmed — query refused."
